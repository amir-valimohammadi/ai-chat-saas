# قیمت‌گذاری اولیه

قیمت‌های مصوب این مرحله، ماهانه هستند:

| پلن | تومان برای نمایش | ریال برای ذخیره در `price_monthly` |
| --- | ---: | ---: |
| Basic | ۳۹۰٬۰۰۰ | 3,900,000.00 |
| Growth | ۸۹۰٬۰۰۰ | 8,900,000.00 |
| Pro | ۱٬۹۹۰٬۰۰۰ | 19,900,000.00 |

کاتالوگ با واحد ریال ذخیره می‌شود. فرم مدیریت پلن مبلغ تومان می‌گیرد و تبدیل صریح انجام می‌دهد. API ایجاد/ویرایش پلن باید `price_currency: IRR` دریافت کند؛ فرانت‌اند و بک‌اند هم‌زمان منتشر شوند. واحد و مبلغ سوابق مالی قبلی تغییر نکرده‌اند.

## اجرای کنترل‌شده روی دیتابیس مقصد

ابتدا بکاپ قابل بازیابی تهیه و اتصال دیتابیس مقصد را کنترل کنید. از ریشه مخزن، پیش‌نمایش بدون ذخیره:

```text
php backend/cli/apply-launch-pricing.php
```

تنها پس از بررسی پیش‌نمایش، ثبت قیمت‌ها:

```text
php backend/cli/apply-launch-pricing.php --apply
```

در ویندوز می‌توان به‌جای `php` از `C:/xampp/php/php.exe` استفاده کرد. ابزار فقط برای شناسه‌های ۱/۲/۳ با نام‌های Basic/Growth/Pro طراحی شده است و فقط قیمت قبلی صفر یا قیمت مصوب را می‌پذیرد. با نام، شناسه یا قیمت متفاوت، ابتدا علت تفاوت را بررسی کنید؛ محافظ را برای عبور اجباری حذف نکنید. اجرای تکراری روی نتیجه همین مرحله تغییری نمی‌دهد و تغییر قیمت آینده مدیر را بازنویسی نمی‌کند.

عملیات تراکنشی است و تغییرات در audit ثبت می‌شوند. تنها قیمت کاتالوگ و فعال‌بودن پاسخ خودکار سه پلن تنظیم می‌شود؛ ظرفیت‌ها ثابت می‌مانند. ابزار ثابت‌ماندن فیلدهای مالی/شرایط اصلی اشتراک‌ها و پرداخت‌ها را نیز کنترل می‌کند. این اسکریپت ابزار تمدید اشتراک، وصول وجه یا اصلاح تاریخچه نیست.

## محدودیت‌ها و تست

- مبلغ پیشنهادی دوره سه‌ماهه و سالانه برابر سه و دوازده برابر قیمت ماهانه است؛ تخفیف خودکاری وجود ندارد. مدیر مبلغ نهایی را تأیید می‌کند.
- ارزهای IRR و IRT برای مبلغ پیشنهادی پشتیبانی می‌شوند؛ برای ارزهای دیگر، مبلغ باید صریحاً وارد شود و نرخ تبدیل فرضی نداریم.
- دوره رایگان ۱۴روزه، پلن رایگان دائمی و درگاه پرداخت بخشی از این تغییر نیستند.
- سقف‌های پلن به معنی تضمین ظرفیت هم‌زمان نیستند؛ آزمون بار قبل از فروش لازم است.
- تست مبلغ با Node.js 24 از پوشه `frontend`: `node scripts/check-plan-money.mjs`؛ ۲۵ بررسی.
- تست HTTP روی محیط محلی با Apache/MariaDB روشن، از ریشه پروژه: `php backend/cli/customer-plan-smoke-test.php`؛ ۳۵ بررسی و پاک‌سازی داده مصنوعی. روی دیتابیس مشتری اجرا نشود.
