# AI Chat SaaS

ساختار اولیه پروژه چت آنلاین + دستیار AI.

## بخش‌ها

- `backend/`: بک‌اند PHP خام و APIها
- `frontend/`: پنل مدیریت با Next.js و React
- `widget/`: ویجت چت قابل نصب روی سایت مشتری

## مسیرهای مهم

- `backend/config/database.php`
- `backend/includes/response.php`
- `backend/includes/cors.php`
- `backend/api/auth/login.php`
- `frontend/app/login/page.tsx`
- `widget/src/widget.js`
